## Salam Sejahtera,

Saya menulis surat ini atas nama pasukan pembangunan **PustakaHadith**, sebuah aplikasi desktop sumber terbuka (open-source) untuk membaca dan mencari hadis daripada 9 kitab utama (Kutub al-Tis'ah) — **62,169 hadis** — dengan carian kata kunci, carian makna (AI), transliterasi, darjat ulama, dan huraian ringkas.

### Latar Belakang

Aplikasi ini dibangunkan untuk kegunaan am umat Islam di Malaysia dan serantau, dengan matlamat:
- Memudahkan akses ke teks hadis asal (Arab) dan terjemahan Melayu/Indonesia
- Menyediakan carian makna (semantic search) menggunakan AI model `intfloat/multilingual-e5-small` yang berjalan **sepenuhnya luar talian** (on-device)
- Memaparkan darjat ulama (Sahih/Hasan/Da'if) berdasarkan penilaian para sarjana
- **Mempaparkan huraian ringkas daripada SemakHadis.com** sebagai nilai tambah untuk pemahaman hadis

### Butiran Penggunaan Kandungan SemakHadis.com

| Item | Butiran |
|---|---|
| **Jenis kandungan** | Huraian ringkas hadis (teks ringkas penjelasan) |
| **Jumlah hadis berkenaan** | 4,237 hadis (hanya yang ada huraian di SemakHadis.com) |
| **Cara paparan** | Dalam butiran hadis, di bawah teks Arab/terjemahan, dengan **atribusi jelas** "Sumber: SemakHadis.com" |
| **Mod aplikasi** | Luar talian (offline-first) — data disimpan dalam SQLite (`hadis.db`) dalam peranti pengguna |
| **Edaran** | Microsoft Store (MSIX), Pemasang EXE (Inno Setup), ZIP portable — **percuma, tiada iklan, tiada komersial** |
| **Lesen kod sumber** | MIT License (GitHub) |

### Permohonan

Kami mohon dengan hormat **kebenaran bertulis** daripada SemakHadis.com untuk:

1. ✅ **Menggunakan huraian ringkas** (4,237 rekod) dalam aplikasi PustakaHadith
2. ✅ **Mengedarkan aplikasi** melalui Microsoft Store dan saluran lain (percuma)
3. ✅ **Mengekalkan atribusi** "Sumber: SemakHadis.com" pada setiap huraian
4. ✅ **Tidak mengubahsuai** teks huraian asal (dipaparkan sebagaimana adanya)

### Manfaat kepada SemakHadis.com

- **Pengenalan jenama** kepada ribuan pengguna aplikasi hadis
- **Trafik rujukan** — pengguna boleh melayari laman web SemakHadis.com untuk huraian penuh
- **Khidmat umat** — memudahkan akses ilmu hadis kepada golongan awam
